# 🇰🇪 NYIKAROAM KENYA

### AI-Powered Tourism and Destination Discovery Platform

**Discover Kenya. Explore More.**

Nyikaroam Kenya is a tourism technology platform designed to help local and international travellers discover Kenya's beautiful tourism destinations through personalised recommendations, destination search and interactive maps.

## 🌍 Project Overview

The platform aims to promote Kenyan tourism by making it easier to discover wildlife parks, beaches, cultural attractions and other destinations.

## ✨ Key Features

- Destination discovery and exploration.
- Personalised tourism recommendations.
- User registration and login.
- Save favourite destinations.
- Interactive destination maps.
- Destination search and filtering.
- User feedback.
- Administrator dashboard.

## 🚀 Project Setup

### Backend

```bash
cd backend
py -m venv venv
```

Install dependencies:

```bash
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

Create your `.env` file using `.env.example`, then run:

```bash
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Backend documentation:

http://127.0.0.1:8000/docs

### Frontend

Open another terminal:

```bash
cd frontend
npm.cmd install
npm.cmd run dev
```

Open the local URL provided by Vite.
